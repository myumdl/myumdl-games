# myumdl-games · 直播里 AI 现场写的小游戏

小红书直播「AI 现场写游戏」的源码。每周一、三、五中午一场, 全程不手写代码, 只用中文跟 AI (Claude Code) 说需求, 一小时分四步把游戏做出来。

每款都是**一个 HTML 文件**, 不依赖任何外部库, 下载下来浏览器双击打开就能玩。

## 游戏

| 场次 | 游戏 | 目录 | 怎么玩 |
|------|------|------|--------|
| L01 | 小球逃脱 | `live/L01-ball-escape/` (直播后上传) | 按 N 粘贴名单「昵称 语言」, 空格重开, M 静音 |
| L02 | 石头剪刀布大军 | `live/L02-rps-army/` (直播后上传) | 按 N 粘贴名单「昵称 派别或语言」, 空格重开, M 静音 |

## 说明

- 代码是直播现场 AI 生成的原样, 没有事后手改; 每场的提示词也放在对应目录里。
- 想自己试: 把提示词按顺序贴给任意 AI 编程工具, 每次生成的结果都会有点不一样, 这很正常。
